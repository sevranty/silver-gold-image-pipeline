# Silver-Gold Image Pipeline v0.1.0

First production release of the mono-style reference-to-image Agent Skill.

Highlights:

- compact canonical `SKILL.md` orchestration;
- Silver-Gold style contract with 70–85% structural silver and 15–30% gold accents;
- reference roles, locks, scene, prompt, QA, safety, adapter, and delivery contracts;
- offline validators with stable exit codes and JSON reports;
- trigger, workflow, rejection, and manual visual regression evidence;
- plugin packaging, deterministic archive manifest, checksums, and installation smoke test.

Runtime generation/editing capability is detected at execution time and is not bundled. Visual quality remains subject to manual review. Exact main SHA and final checksums are inserted at release publication.
