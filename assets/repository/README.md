# Repository social preview assets

- `repository-social-preview-source.svg` is the editable original source
- `repository-social-preview.png` is the 1280 x 640 production upload
- `repository-social-preview-manifest.json` stores dimensions, hashes, alt text, QA and publication state
- `proofs/` contains crop, small-size, light-surrounding and dark-surrounding checks

All visual material is original to SGP. No third-party image, screenshot, logo, font file or remote SVG resource is embedded.

The production PNG is ready for GitHub Settings upload. Its presence in the repository does not prove that GitHub is displaying it.
