# Changelog

All notable changes to this project are documented here. Versions follow Semantic Versioning for each independently versioned contract.

## [0.1.0] - 2026-07-15

### Added

- canonical mono-style Silver-Gold Agent Skill orchestration;
- style, background, reference, lock, prompt, QA, delivery, safety, and adapter contracts;
- deterministic static validation and non-destructive asset packaging;
- trigger, workflow, rejection, provenance, and manual visual regression evidence;
- plugin manifest, installation smoke test, release contract, and package checksums.

### Constraints

- image generation/editing capability is runtime-detected and is not bundled;
- visual quality remains a manual decision;
- version 0.1.0 is prepared for release but is not tagged or published by the packaging task.
